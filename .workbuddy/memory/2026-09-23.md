### 踩到的坑（可复用）

1. 🚨 **MuMu 模拟器是横屏解析**：`wm size` 报 `1080x1920`，但
   `dumpsys window displays` 给 `cur=1920x1080`、`SurfaceOrientation: 1`。
   **tap 坐标必须按横屏 1920×1080 算**，否则点击静默无效（截图字节数完全一致 = 没生效）。
   正确做法：`uiautomator dump` 取 `bounds` 解析中心点，别用截图目测估算。
   底部 tab 实际 y ≈ 1010~1038，x = 234 / 717 / 1200 / 1685。
2. 🚨 **Bash 里 `\` 转义的 `git commit -F /dev/stdin << EOF` 不可用**（Git Bash 读不到
   `/dev/stdin`）。必须先 Write 一个 commitmsg 文件再 `git commit -F <file>`。
3. `GIT_TERMINAL_PROMPT=0 git push` → **推送成功**。Windows 凭据管理器里有 GitHub 条目
   （`cmdkey /list` 可见），git 能走它；但**该凭据不给 API 写权限**，
   `PATCH /repos/...` 仍返回 401 `Requires authentication`。
   → 改仓库 description / topics / homepage **必须用户在网页上手动操作**，本机无解。
4. Pillow 在隔离环境里：`C:/Users/admin/.workbuddy/binaries/python/envs/default/Scripts/python.exe`
   （系统 python 3.13.12 没有 PIL）。

### 🚨 截图务必用竖屏（本次最大的坑）

MuMu 那个实例原本是 `resolution_mode = tablet.1` / **1920×1080（横屏）**，
截出来的 UI 被横向拉宽，很难看。正确做法：

1. `MuMuManager.exe setting -v 0 -k resolution_mode -val custom`
2. `-k resolution_width.custom -val 1080`、`-k resolution_height.custom -val 1920`
3. **必须重启实例**才生效（`control -v 0 shutdown` → `launch`）
4. 🔴 改完 `Physical density` 会掉到 **10**，界面挤成一团、字体变点阵。
   必须 `adb shell wm density 440` 覆盖回来（440 实测正常；480 也还行但偏紧）。
5. 竖屏下 tab 坐标：y≈1854，x = 126 / 401 / 676 / 953。
6. 用完记得复原：`wm density reset` + `resolution_mode` 回 `tablet.1`（1920×1080）。

图片布局也从「两行两列横屏拼图」改成「**四台手机竖屏并排**」（1198×562），
