# 未竟 · Weijing

**欢迎使用「未竟」。** 这是一个纯自用的小工具，全部由 AI 生成，没有一行手写。

它是一个 Android 习惯打卡 App，数据全部存在本地，不需要注册，也不上传任何东西。

当前版本 **1.4.1** · 适用于 Android 10 ~ 15

## 功能介绍

### 今日
- 顶部进度卡：今天要完成几项、已经完成几项
- 今日计划列表：支持带子任务的大计划（逐项勾选），以及计数器型习惯（比如「喝水 3 杯」，点一次加一杯）
- 当天没有排期时，会给出说明以及未来 60 天内即将到来的计划
- 底部一句话每日格言，断网时自动使用内置的 64 条语录

### 历史
- 月历视图：每一天用状态点标出「已完成 / 部分完成 / 未完成」，可以翻月和跳回今天
- 点任意一天查看当天完整清单，漏掉的那天可以补打卡
- 下方是倒序的打卡记录，点缩略图可以全屏查看照片凭证

### 计数器
- **独立计数器**：和习惯分开的计数工具，比如「冰箱里的可乐还剩几罐」
- 可以设置上限，自定义步长和单位
- **自动周期归零**：按天 / 周 / 月 / 每 N 天重置，归零时把上一周期的结果写进历史，记录不会丢

### 管理中心
- 视觉效果：6 套配色（宣纸 / 雾霭 / 青瓷 / 墨曜 / 午夜 / 暖夜），也可以跟随系统
- 计划清单：集中管理所有习惯和计划，支持归档
- 数据备份：导出 / 导入 JSON，换手机时用它迁移
- 提醒设置：通知权限引导、音量诊断
- 关于：版本信息、手动检查更新

### 其他
- 每个计划可以单独设置提醒时间和图标、颜色
- 打卡、撤销、计数达标都有各自的触感和提示音，可以分别关闭
- 支持深色模式，界面字号可调（小号 / 标准 / 大号 / 特大号）
- 有新版本时会提示更新，可以直接在应用内下载安装

## 安装

下载 `app-release.apk` 安装即可。首次安装需要在系统设置里允许安装未知来源的应用。
